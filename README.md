NaNoGenMo 2026 - Linguistic Rewilding Pipeline
Project Purpose
The Linguistic Rewilding Pipeline is an experimental physics engine and digital publisher developed for National Novel Generation Month (NaNoGenMo) 2026. Executed entirely via book.py, the system ingests standard text and systematically translates human language structures into non-human vocalizations using Z-Axis Deep Map continuous character mapping (macro/micro waves), simulating an organic shift from structured syntax back into raw, environmental acoustic events rendered directly into a structurally identical typeset PDF.
Transformation Workflow
The execution pipeline in book.py processes input text using a three-tier calculation logic to establish baseline threshold averages across structural units and determine the loci of rewilding:

Tiered Threshold Calculation — Analyzes paragraphs (Tier 3), sentences (Tier 2), and words (Tier 1) to calculate structural averages (sentences per paragraph, words per sentence, and syllables per word).
Locus Identification — When a token breaches these calculated averages, it serves as an acoustic locus that triggers a rewilding wave.
Cascading Wave Processing — Wave processing cascades from Macro (Tier 3) down to Micro (Tier 1), tracking transformation states using is_locus flags across a continuous character array rather than passing sequential text chunks.
Output Artifact
Typeset PDF: A structurally identical layout document rendered with custom visual typography, representing the sole output artifact generated by the pipeline.
Setup Instructions
Environment Dependencies
Ensure Python 3.x is installed along with the required execution dependencies for book.py:

FPDF (PDF generation)
Pillow / PIL (Image processing)
NLTK (Linguistic tokenization and parsing)
Required Directory Structure
All script execution relies on relative assets. Keep book.py and the following assets within the same root directory:

Filename
Description
book.py
Main execution pipeline script containing Z-Axis Deep Map logic
sounds.jsonl
Phoneme-to-vocalization mapping database
baskerville.ttf
Serif font for primary text elements
gwendolyn.ttf
Display font for vocalization notation


Run the generation pipeline via:
python book.py
